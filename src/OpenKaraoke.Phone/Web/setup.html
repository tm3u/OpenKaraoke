下載憑證

用「檔案」開啟憑證

檔案 App → 下載項目

點選 OpenKaraoke-Local-CA.cer，依提示允許加入描述檔。

Safari 已顯示「已下載描述檔」？

可直接按「下一步」前往安裝。只下載到「檔案」，還不代表已安裝。

安裝憑證

設定 → 已下載描述檔

選擇 OpenKaraoke 的憑證，按右上角「安裝」，依提示輸入手機解鎖密碼並完成安裝。

找不到「已下載描述檔」？

到「設定 → 一般 → VPN 與裝置管理」查看。尚未安裝的描述檔會在下載 8 分鐘後被刪除；回「檔案」重新點開憑證，再進行安裝。

開啟完整信任

設定 → 一般 → 關於本機
→ 憑證信任設定

找到 OpenKaraoke Local Microphone CA，開啟完整信任的開關，並確認系統提示。

完整信任開關應為開啟。只安裝憑證，或在 Safari 警告中按「允許」，都不算完成這一步。

Android：安裝 CA 憑證

在手機的安全性設定中，安裝剛下載的 OpenKaraoke-Local-CA.cer，憑證用途選擇 CA 憑證。

選單位置依手機品牌不同，請依系統提示完成安裝。

掃描「連接麥克風」

回到電腦的手機麥克風設定，用相機掃描右側「連接麥克風」QR Code，再用手機瀏覽器開啟。

左側「首次設定」用來安裝憑證；接下來請用右側 QR Code 收音。

如何確認開對頁面？

網址以 https:// 開頭，預設使用 8443 連接埠。頁面會顯示「手機麥克風」及「開啟麥克風」按鈕。iPhone 請使用 Safari。

開啟麥克風

在剛開啟的收音頁按「開啟麥克風」，並允許使用麥克風。等待連線完成，看到「收音中」再說話測試。

回到電腦按「測試收音」，確認有聲音後，再按「套用」保存來源；按「取消」會恢復原設定。

螢幕常亮與停止收音

最多兩支手機同時收音。收音時會要求螢幕常亮，請保持此頁面開啟並避免手動鎖屏。若無法常亮，可關閉低耗電模式後重新開啟麥克風，或暫時將 iPhone「設定 → 螢幕顯示與亮度 → 自動鎖定」設為「永不」。

要停止收音，按「關閉麥克風」。

需要協助？

信任設定找不到憑證

只有下載還不夠。iPhone 請先完成描述檔安裝，再開啟完整信任。

仍有私人連線警告

iPhone 請確認完整信任已開啟；Safari 的「允許」不能代替這個設定。關閉失敗的分頁，再掃描「連接麥克風」。

顯示「尚未配對」

重新掃描電腦目前的「連接麥克風」QR Code。停用、重啟服務或更換網路後，舊網址可能已失效。
